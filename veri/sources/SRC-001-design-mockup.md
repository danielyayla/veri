Interactive HTML mockup of the desktop UI, produced from the original
design brief (project then named Kiln; v2 renames all product surfaces to
Veri). Contains the full "skiff" demo dataset (invoicing app: requirements,
decisions incl. a supersession chain, work orders with receipts, sources)
and the Context Package panel design. Key extractions: package rules
wording (adopted into [[REQ-003]]), receipts-per-session model (adopted as
[[DEC-003]]), demo fixture content (ported in [[WO-004]]).

v2 (2026-08-07): current file is `design/design-mockup.html`, a
self-contained single file — open directly in a browser; all five screens
are switchable from its sidebar. A full written design spec (tokens,
measurements, interactions) accompanies it as `design/README.md`. The
mockup's demo IDs (skiff dataset) are illustrative and do not correspond
to this repo's documents. UI implementation is tracked in [[REQ-004]] /
[[WO-005]].
