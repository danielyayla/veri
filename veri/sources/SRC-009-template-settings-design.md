High-fidelity written design handoff for the per-project template
settings view required by [[REQ-010]], a thin UI over the
`veri/templates/<type>.md` files chosen in [[DEC-023]]. Files live in
`design/template-settings/`:

- `README.md` — self-sufficient written spec: entry points (a `⚙`
  Settings rail button above the agent button, plus a command-palette
  view row), the Templates view layout (210px type list + editor
  card, 920px centered), the `default`/`custom` state chips computed
  by comparing the project file to the built-in default, the locked
  frontmatter preview labeled "generated by veri — not part of the
  template" that teaches the REQ-010 body-only boundary, editing
  semantics inherited from the markdown editor ([[SRC-008]]: ⌘S,
  dirty dot, conflict banner — but no guarded ranges and no `[[`
  autocomplete), the inline-confirm Reset to default, and edge states
  (missing `veri/templates/`, unreadable file).
- `template-settings.html` — self-contained interactive prototype
  (open in a browser; illustrative "skiff" fixture content). Its
  textarea editor is a stand-in for the CodeMirror 6 island — a
  design reference, not production code.

The spec introduces no new design tokens — every color, font, and
radius reuses the canon in `design/README.md`; rail and tab behavior
extend the navigation-model ([[SRC-005]]) and document-tabs
([[SRC-004]]) bundles unchanged.
