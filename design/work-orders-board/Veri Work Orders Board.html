Design notes

answers to SRC-025
Entry point

The Work Orders collection opens a ▤ Work Orders view tab, the same way Home and Search open as tabs. The type panel and its Backlog / In progress groups stay untouched — the board is a second door, not a replacement.

Scale

SRC-025 killed the old board because DONE was uncapped. Here the done column is windowed to the five most recently updated, with a ▸ show all expander. Living columns render in full — they're small by the lifecycle's nature.

The ready lane

The column WO-098 deferred to the app: ready is entered only by the user's stamp (veri approve), and veri next dispatches from it — so the lane reads "cleared, awaiting an agent." Proposed color: the info blue (--t-req hue); amber rejected (reads as draft/health warning), green rejected (collides with done).

Card anatomy

Cards earn each element: mono type-colored ID, title, and a recency line the type panel can't show — updated Nd ago answers "is this stale?" at a glance. Done cards swap it for the receipt SHA. The amber dot marks a veri check issue (filled = issue, per SRC-010).

Out of scope

No drag-and-drop. Status changes stay on the work-order detail's segmented control, per WO-053's ruling — and backlog → ready is a stamped promotion no UI control may perform. Cards are buttons: click for a preview tab, double-click to pin.
