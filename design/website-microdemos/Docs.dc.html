Quickstart

From install to an agent that reads your project's knowledge base — about ten minutes, using the bundled sample project as the worked example.

You'll need: a coding agent that speaks MCP (the steps below use Claude Code) and Node 20+ on your machine. The Veri app needs macOS 13 or later; the CLI, MCP server, and GitHub Action run anywhere Node 20+ does.

1. Install Veri

$ npm install -g @verikb/cli
{{ copyLabel }}

Prefer the app? Download the DMG for your Mac's chip — it's signed and notarized, so macOS opens it without warnings.

2. Open the sample project

On first launch, the app shows a welcome screen with three choices. Pick Explore the sample project — a working invoicing-app knowledge base with sixteen documents you can read, edit, and connect an agent to. Installed the CLI instead? veri init --demo scaffolds a starter knowledge base in the current directory.

Nothing is written until you confirm. Veri shows you exactly what it will create before it creates anything. The other two cards — a new empty project, or a folder that already has a veri/ directory — work the same way.

3. Look around

You land on the home view. The sidebar groups documents by type — requirements, decisions, work orders, sources — and every one of them is a plain Markdown file. NEEDS REVIEW shows one draft requirement waiting for approval, and HEALTH shows two veri check findings left in on purpose.
